# Fortanix

Fortanix is a data-security company building the Fortanix Data & AI Security Platform,
a unified control plane for enterprise cryptography.

- Website: https://www.fortanix.com/
- Developer portal: https://support.fortanix.com/
- API references: https://www.fortanix.com/api
- GitHub: https://github.com/fortanix

- Trust center: https://www.fortanix.com/trust-center
